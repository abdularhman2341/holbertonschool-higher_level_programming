# JavaScript DOM Manipulation

This project introduces JavaScript DOM manipulation, event handling, and the Fetch API.

## Learning Objectives

By the end of this project, I learned how to:

- Select HTML elements using `document.querySelector`
- Modify the style of HTML elements
- Handle user events with `addEventListener`
- Add, check, and replace CSS classes using `classList`
- Create new HTML elements with `document.createElement`
- Add elements to the DOM with `appendChild`
- Update element content using `textContent`
- Fetch data from APIs using the Fetch API
- Work with JSON responses
- Iterate through API results
- Wait for the DOM to load using `DOMContentLoaded`

## Files

### 0-script.js

Changes the text color of the `header` element to red.

### 1-script.js

Changes the text color of the `header` element to red when the user clicks on the element with the id `red_header`.

### 2-script.js

Adds the `red` class to the `header` element when the user clicks on the element with the id `red_header`.

### 3-script.js

Toggles the `header` element between the `red` and `green` classes when the user clicks on the element with the id `toggle_header`.

### 4-script.js

Creates and adds a new `<li>Item</li>` element to the list with the class `my_list` when the user clicks on the element with the id `add_item`.

### 5-script.js

Updates the text of the `header` element to `New Header!!!` when the user clicks on the element with the id `update_header`.

### 6-script.js

Fetches a Star Wars character from the SWAPI API and displays the character's name in the element with the id `character`.

### 7-script.js

Fetches Star Wars movies from the SWAPI API and displays their titles as list items inside the element with the id `list_movies`.

### 8-script.js

Fetches the French translation of "hello" and displays it in the element with the id `hello`.

The script waits for the DOM to finish loading before accessing the HTML element.
