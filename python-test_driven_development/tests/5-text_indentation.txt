========================================
How to Use 5-text_indentation.py
========================================

Import the function:
    >>> text_indentation = __import__('5-text_indentation').text_indentation

Test with normal text:
    >>> text_indentation("Hello. How are you? I am fine: great.")
    Hello.
    <BLANKLINE>
    How are you?
    <BLANKLINE>
    I am fine:
    <BLANKLINE>
    great.
    <BLANKLINE>

Test with extra spaces that should be ignored:
    >>> text_indentation("  Hello.   Spaces   ?  Yes:  ")
    Hello.
    <BLANKLINE>
    Spaces   ?
    <BLANKLINE>
    Yes:
    <BLANKLINE>

Test with non-string:
    >>> text_indentation(123)
    Traceback (most recent call last):
        ...
    TypeError: text must be a string
