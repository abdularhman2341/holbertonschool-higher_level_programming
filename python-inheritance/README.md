# Python - Inheritance

This repository contains Python scripts demonstrating the concepts of object inheritance, type checking, and class properties in Python.

## Files Description

| File | Description |
| ------ | ------ |
| `0-lookup.py` | A function that returns the list of available attributes and methods of an object. |
| `1-my_list.py` | A class `MyList` that inherits from `list` with a method to print the list sorted. |
| `2-is_same_class.py` | A function that checks if an object is exactly an instance of a specified class. |
| `3-is_kind_of_class.py` | A function that checks if an object is an instance of, or inherited from, a specified class. |
| `4-inherits_from.py` | A function that checks if an object inherited directly or indirectly from a class (excluding the class itself). |
| `5-base_geometry.py` | An empty class `BaseGeometry`. |
| `6-base_geometry.py` | A class `BaseGeometry` with an unimplemented `area()` method that raises an Exception. |

## Usage
All files are written in Python 3 and are executable. To test individual files, you can use the provided `main.py` files in the prompt.
