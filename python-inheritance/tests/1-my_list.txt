=============================
How to use 1-my_list
=============================

    >>> MyList = __import__('1-my_list').MyList

Test standard list of positive integers:
    >>> my_list = MyList()
    >>> my_list.append(1)
    >>> my_list.append(4)
    >>> my_list.append(2)
    >>> my_list.append(3)
    >>> my_list.append(5)
    
    >>> print(my_list)
    [1, 4, 2, 3, 5]
    
    >>> my_list.print_sorted()
    [1, 2, 3, 4, 5]
    
    >>> print(my_list)
    [1, 4, 2, 3, 5]

Test with empty list:
    >>> empty_list = MyList()
    >>> print(empty_list)
    []
    
    >>> empty_list.print_sorted()
    []
    
    >>> print(empty_list)
    []

Test with negative numbers:
    >>> neg_list = MyList()
    >>> neg_list.append(-5)
    >>> neg_list.append(-1)
    >>> neg_list.append(-3)
    
    >>> print(neg_list)
    [-5, -1, -3]
    
    >>> neg_list.print_sorted()
    [-5, -3, -1]
    
    >>> print(neg_list)
    [-5, -1, -3]
