# Python - Everything is object

This project explores how Python handles objects, references, assignments, aliases, mutable objects, and immutable objects.

## Learning Objectives

By the end of this project, I should be able to explain:

- What an object is
- The difference between a class and an object or instance
- The difference between mutable and immutable objects
- What a reference is
- What an assignment is
- What an alias is
- How to check if two variables are identical
- How to check if two variables refer to the same object
- How to display the identifier of an object
- Built-in mutable types
- Built-in immutable types
- How Python passes variables to functions

## Requirements

- Python 3.8.5
- Ubuntu 20.04 LTS
- Python files must start with `#!/usr/bin/python3`
- Python files must follow pycodestyle 2.7.*
- All files must end with a new line
- `.txt` answer files contain only one line and do not include a shebang
